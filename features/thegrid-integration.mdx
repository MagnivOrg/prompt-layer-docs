[The Grid](https://thegrid.ai) is an inference marketplace that serves models from several labs behind one OpenAI-compatible API. Instruments address a **capability tier** rather than a specific lab's model name — `text-standard`, `code-prime` and `agent-max` each route to a current model for that tier — so a prompt template keeps working when the underlying model is replaced.

## Setting Up The Grid as a Custom Provider

To use The Grid instruments in PromptLayer:

1. Navigate to **Settings → Custom Providers and Models** in your PromptLayer dashboard
2. Click **Create Custom Provider**
3. Configure the provider with the following details:
   - **Name**: The Grid (or your preferred name)
   - **Client**: OpenAI
   - **Base URL**: `https://api.thegrid.ai/v1`
   - **API Key**: Your The Grid API key (get one at [thegrid.ai](https://thegrid.ai))

<Note>
The Grid uses OpenAI-compatible endpoints, which is why we select OpenAI as the client type.
</Note>

## Creating Custom Models (Recommended)

For easier model selection in the Playground and Prompt Registry, create custom models:

1. In **Settings → Custom Providers and Models**, find your The Grid provider in the list
2. Click on the row to expand it
3. Click **Create Custom Model**
4. Configure each model:
   - **Provider**: Select the The Grid provider you created
   - **Model Name**: The instrument identifier (e.g., `text-standard`, `agent-max`)
   - **Display Name**: A friendly name like "Text Standard"
   - **Model Type**: Chat
5. Repeat for each instrument you want to use

## Available Instruments

Instruments come in capability tiers across text, code and agent families:

| Instrument | Use it for |
| --- | --- |
| `text-standard` | General conversation and high-volume generation |
| `text-prime`, `text-max` | Harder reasoning, at higher latency and cost |
| `code-standard`, `code-prime`, `code-max` | Reading and writing code |
| `agent-standard`, `agent-prime`, `agent-max` | Multi-step tool use |

There are also lab-pinned instruments such as `claude-opus-latest`, `gemini-pro-latest` and `deepseek-pro-latest`.

`GET https://api.thegrid.ai/v1/models` returns the complete, current list with context windows and capability flags. For details, see [The Grid's instrument specifications](https://thegrid.ai/docs/instrument-specifications/current-instruments).

## Using The Grid in PromptLayer

### In the Playground

1. Open the Playground
2. Select your The Grid provider from the provider dropdown
3. Choose an instrument
4. Start querying with your prompts

### In the Prompt Registry

Instruments work with PromptLayer's Prompt Registry — select them when creating or editing templates, use those templates in evaluations, and track usage alongside your other providers.

### Reasoning and token budgets

<Warning>
Instruments reason before answering, and reasoning tokens count toward `max_tokens` while never appearing in the response. If replies come back truncated, raise `max_tokens` rather than lowering it.

On one short prompt, `text-standard` spent 114 of a 250-token budget on reasoning, and `agent-max` hit the cap and stopped with `finish_reason: "length"`. Use `reasoning_effort` (`low`, `medium`, `high`, and on `*-max` instruments also `xhigh` and `max`) to control how much reasoning is performed.
</Warning>

## SDK Usage

Once you've set up the provider and created a prompt template in the dashboard, run it with the PromptLayer SDK:

```python
from promptlayer import PromptLayer

promptlayer = PromptLayer(api_key="pl_****")

# Run a prompt template configured to use a The Grid instrument
response = promptlayer.run(
    prompt_name="your-thegrid-prompt",
    input_variables={"topic": "quantum computing"}
)

print(response["raw_response"].choices[0].message.content)
print(f"Request ID: {response['request_id']}")
```
