[Heabsy](https://heabsy.com/platform) is an OpenAI-compatible inference API for open models, operated by FEYA, s.r.o. (Slovakia). Models in its EEA tier run on dedicated GPUs in EEA data centres with zero data retention, which suits teams whose prompts must be processed in Europe.

## Setting Up Heabsy as a Custom Provider

To use Heabsy models in PromptLayer:

1. Navigate to **Settings → Custom Providers and Models** in your PromptLayer dashboard
2. Click **Create Custom Provider**
3. Configure the provider with the following details:
   - **Name**: Heabsy (or your preferred name)
   - **Client**: OpenAI
   - **Base URL**: `https://api.heabsy.com/v1`
   - **API Key**: Your Heabsy API key. Keys are issued in the [Heabsy console](https://platform.heabsy.com); accounts are opened on request at [heabsy.com/contacts](https://heabsy.com/contacts)

<Note>
Heabsy uses OpenAI-compatible Chat Completions endpoints, which is why we select OpenAI as the client type.
</Note>

## Creating Custom Models (Recommended)

For easier model selection in the Playground and Prompt Registry, you can create custom models:

1. In **Settings → Custom Providers and Models**, find your Heabsy provider in the list
2. Click on the Heabsy row to expand it
3. Click **Create Custom Model**
4. Configure each model:
   - **Provider**: Select the Heabsy provider you created
   - **Model Name**: Enter the Heabsy model identifier (e.g., `qwen38`)
   - **Display Name**: A friendly name like "Qwen3.8 27B (Heabsy)"
   - **Model Type**: Chat
5. Repeat for each model you want to use

## Available Models

Example model:

- **`qwen38`**: Qwen3.8 27B, served in the EEA tier (262k context, tool calling)

The [Heabsy model catalog](https://heabsy.com/models) lists all model identifiers, their prices, and which models run in the EEA tier. `GET https://api.heabsy.com/v1/models` returns the models available to your key.

## Using Heabsy in PromptLayer

### In the Playground

1. Open the Playground
2. Select your Heabsy provider from the provider dropdown
3. Choose your model
4. Start querying with your prompts

### In the Prompt Registry

- Select Heabsy models when creating or editing prompt templates
- Use templates with Heabsy models in evaluations
- Track Heabsy usage alongside other providers

## SDK Usage

Once you've set up your Heabsy custom provider and created a prompt template in the dashboard, you can run it with the PromptLayer SDK:

```python
from promptlayer import PromptLayer

promptlayer = PromptLayer(api_key="pl_****")

# Run a prompt template that uses your Heabsy custom provider
response = promptlayer.run(
    prompt_name="your-heabsy-prompt",
    input_variables={"topic": "data residency"}
)

print(response["raw_response"].choices[0].message.content)
print(f"Request ID: {response['request_id']}")
```
