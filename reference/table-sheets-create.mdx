---
title: "Create Sheet"
openapi: "POST /api/public/v2/tables/{table_id}/sheets"
---

Create a new sheet in a table. Omit `source` to create an empty sheet synchronously, then add columns and rows with the column and row endpoints. Provide `source` to import data from a file or request logs asynchronously.

## Behavior Notes

- Without `source`, PromptLayer creates an empty sheet and returns `201`.
- With `source.type=file` or `source.type=request_logs`, the import runs asynchronously and the endpoint returns `202`. Poll [Get Sheet Import Operation](/reference/table-sheets-get-operation) until the operation reaches `succeeded` or `failed`.
