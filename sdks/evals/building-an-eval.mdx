An eval file defines `evaluate(...)`, then you run:

```bash
promptlayer eval run path/to/your.eval.py
```

## Minimal example

<CodeGroup>
```python Python
from openai import OpenAI
from promptlayer import evaluate, contains_scorer

client = OpenAI()

def run_llm(user_message: str) -> str:
    completion = client.chat.completions.create(
        model="gpt-5.6",
        messages=[
            {"role": "system", "content": "Answer in one short sentence."},
            {"role": "user", "content": str(user_message)},
        ],
    )
    return completion.choices[0].message.content or ""

evaluate(
    "support-reply-eval",
    dataset=[{"input": "How do I reset my password?"}],
    runner=run_llm,
    scorers=[contains_scorer(source="Output", value="reset")],
    passing_score=0.8,
)
```

```javascript JavaScript
import OpenAI from "openai";
import { evaluate, containsScorer } from "promptlayer";

const client = new OpenAI();

async function runLlm(userMessage) {
  const completion = await client.chat.completions.create({
    model: "gpt-5.6",
    messages: [
      { role: "system", content: "Answer in one short sentence." },
      { role: "user", content: String(userMessage) },
    ],
  });
  return completion.choices[0].message.content ?? "";
}

await evaluate("support-reply-eval", {
  dataset: [{ input: "How do I reset my password?" }],
  runner: runLlm,
  scorers: [containsScorer({ source: "Output", value: "reset" })],
  passingScore: 0.8,
});
```
</CodeGroup>

Python async runners use `aevaluate`. JavaScript uses async `evaluate`. Stack examples: [Quickstart](/sdks/evals/quickstart).

## Dataset

Cases feed the runner and scorers:

- `input` — required; passed to the `runner`
- `expected` — expected **output** (Contains, Compare, …)
- `expected_trace` / `expectedTrace` — Trajectory **config** (which tools should run), not the answer text

You can also point `dataset` at a dashboard Table. Details: [Datasets](/sdks/evals/datasets).

## Runner

The `runner` is any callable that takes in an `input` and returns a final value (not a stream). There is no framework allowlist.

For Trajectory, tools must show up as `Tool: <name>` spans on the imported Trace — via a framework helper or `traceTool`. Details: [Runner and tracing](/sdks/evals/agent-tracing).

## Scorers and columns

- **Scorers** become scorecard steps on the experiment sheet. SDK helpers: [Scorers](/sdks/evals/scorers/overview). Behavior of each type: [Scorecards](/features/tables/scorecards) and [Column Types](/features/tables/column-types).
- **Columns** are optional processing steps before scorers. SDK API: [Columns](/sdks/evals/columns/overview). Type reference: [Column Types](/features/tables/column-types).

## Other `evaluate(...)` options

| Goal | Python | JavaScript |
| --- | --- | --- |
| Cases | `dataset` | `dataset` |
| Function under test | `runner` | `runner` |
| Scorecard checks | `scorers` | `scorers` |
| Processing columns | `columns` | `columns` |
| Fail below a bar | `passing_score` | `passingScore` |
| Run cases in parallel | `max_concurrency` | `maxConcurrency` |
| Print failing rows | `include_failure_examples` | `includeFailureExamples` |
| Reuse a Table | `table_id` | `tableId` |
| Folder for a new Table | `folder_id` | `folderId` |
| Experiment sheet name | `experiment_name` | `experimentName` |
| Auth (prefer env for CLI) | `api_key`, `base_url` | `apiKey`, `baseURL` |

Do **not** pass top-level `sheet_id` / `sheetId`. Use `dataset.sheet_id` / `dataset.sheetId` only when the dataset comes from a dashboard sheet.

## What you get back

On success, the SDK creates (or reuses) a Table, writes a dedicated experiment sheet, configures your scorecard, and returns an `EvalResult` with a dashboard URL. See [Results and failures](/sdks/evals/results-and-failures).
