SDK evals measure a function under test from your code. Each eval has three parts:

- **Dataset** — cases with `input` (optional `expected` / expected-trace fields)
- **Runner** — any callable that takes case `input` and returns a final value
- **Scorers** — scorecard checks (Contains, Compare, Trajectory, and more)

Call `evaluate(...)`, then run `promptlayer eval run <path>`. Results write to a [Table](/features/tables/overview) experiment sheet with a dashboard URL.

## How a run works

1. Your `runner` runs once per case under an `Eval: <name>` span.
2. Nested spans attach when they use the active eval tracer.
3. Rows land on an experiment sheet (`Input` / `Expected` / `Output`, plus `Trace` when needed).
4. Scorers run as the sheet scorecard. Optional `passing_score` / `passingScore` fails the process on a miss.
