SDK evals measure a function under test from your code. Each eval has three parts:

- **Dataset** — cases with `input`, plus optional `expected` (expected output) and `expected_trace` / `expectedTrace` (Trajectory config)
- **Runner** — any callable that takes in an `input` and returns a final value
- **Scorers** — scorecard checks (Contains, Compare, Trajectory, and more)

## Why SDK evals

Use SDK evals when the system under test lives in code and you want evals as part of your **testing infrastructure** — local runs, PR checks, and CI — not only experiments you assemble in the dashboard.

- Gate agent or prompt changes with `passing_score` / `passingScore` before merge
- Reuse your real agent entrypoint as the `runner` (any framework or a plain function)
- Land every run on a [Table](/features/tables/overview) experiment sheet you can open in PromptLayer

Use [Tables](/features/tables/overview) in the dashboard when you want to build sheets without a code runner. SDK runs still create Table experiment sheets.

## How a run works

Define `evaluate(...)` in a file, then run `promptlayer eval run <path>`. Each case runs under an `Eval: <name>` span; results land on a Table experiment sheet.

<CodeGroup>
```python Python
from openai import OpenAI
from promptlayer import evaluate, contains_scorer

client = OpenAI()

def run_llm(user_message: str) -> str:
    completion = client.chat.completions.create(
        model="gpt-5.6",
        messages=[
            {"role": "system", "content": "Answer in one short sentence."},
            {"role": "user", "content": str(user_message)},
        ],
    )
    return completion.choices[0].message.content or ""

evaluate(
    "support-reply-eval",
    dataset=[{"input": "How do I reset my password?"}],
    runner=run_llm,
    scorers=[contains_scorer(source="Output", value="reset")],
    passing_score=0.8,
)
```

```javascript JavaScript
import OpenAI from "openai";
import { evaluate, containsScorer } from "promptlayer";

const client = new OpenAI();

async function runLlm(userMessage) {
  const completion = await client.chat.completions.create({
    model: "gpt-5.6",
    messages: [
      { role: "system", content: "Answer in one short sentence." },
      { role: "user", content: String(userMessage) },
    ],
  });
  return completion.choices[0].message.content ?? "";
}

await evaluate("support-reply-eval", {
  dataset: [{ input: "How do I reset my password?" }],
  runner: runLlm,
  scorers: [containsScorer({ source: "Output", value: "reset" })],
  passingScore: 0.8,
});
```
